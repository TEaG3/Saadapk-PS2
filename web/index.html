مختبر اختبار Saad PS2

فحص التخزين

اختبار كتابة وقراءة ومقارنة ملف مؤقت، ثم محاولة حذفه. لا تهيئة ولا حذف لملفات المستخدم.

فهرسة الألعاب

إحصاء ملفات ISO وZSO وCHD وملفات الصور المدعومة، ورصد الملفات الفارغة والتكرارات المحتملة.

فحص أغلفة OPL

مراجعة أنماط أسماء ملفات ART وCOV وICO. لا يدّعي هذا الفحص سلامة الصورة المرئية ما لم تُفحص بياناتها.

تشغيل PCSX2

تطبيق Windows يتيح تحديد ملف المحاكي وملف لعبة محلي تملكه، ثم يسجل حالة العملية ومخرجاتها.

تنبيه مهم: هذه الصفحة تعمل داخل المتصفح للعرض وقراءة التقارير فقط. المتصفح لا يستطيع فحص USB مباشرة أو تشغيل ملفات EXE محلية؛ استخدم تطبيق Windows لهذه الاختبارات.
